# Auto-Language Switcher

โปรแกรมเล็ก ๆ สำหรับ Windows ที่แก้ปัญหา "พิมพ์ผิดภาษา" — ไฮไลต์ข้อความที่พิมพ์ผิดภาษา แล้วกด **Ctrl+Q** ข้อความจะถูกแปลงระหว่างอังกฤษ ↔ ไทย (แป้นพิมพ์เกษมณี) แล้ววางกลับให้ทันที

| พิมพ์ผิดเป็น | กด Ctrl+Q แล้วได้ |
|---|---|
| `l;ylfu` | สวัสดี |
| ้ำสสน | hello |

## วิธีใช้ (ไม่ต้องลง Python)

1. ไปที่หน้า **Releases** (แถบด้านขวาของหน้า repo นี้) แล้วโหลด `AutoLangSwitcher.exe`
2. ดับเบิลคลิกเพื่อเปิด จะมีหน้าต่างเล็ก ๆ ขึ้น **● เปิดอยู่**
3. ไฮไลต์ข้อความในโปรแกรมไหนก็ได้ แล้วกด **Ctrl+Q**
4. ไม่ใช้แล้วกดปุ่ม "ปิดการทำงาน" เพื่อคืนให้ Ctrl+Q ทำงานตามปกติ

> **หน้าจอ "Windows protected your PC":** ไฟล์นี้ไม่ได้เซ็นชื่อดิจิทัล จึงมีหน้าจอเตือนตอนเปิดครั้งแรก ให้กด **More info → Run anyway** โปรแกรมทั้งหมดเป็นโอเพนซอร์ส เปิดดูโค้ดใน `switcher_app.pyw` ได้เลย
> แอนตี้ไวรัสบางตัวอาจเตือนผิด เพราะโปรแกรมนี้ใช้คีย์ลัดและส่งคำสั่งคัดลอก/วาง

## รันจากซอร์สโค้ด

```
pip install -r requirements.txt
python switcher_app.pyw
```

## สร้างไฟล์ .exe เอง

```
pip install pyinstaller pyperclip
pyinstaller --onefile --noconsole --name AutoLangSwitcher switcher_app.pyw
```

ไฟล์จะอยู่ที่ `dist/AutoLangSwitcher.exe`

## หลักการทำงาน

เมื่อกด Ctrl+Q โปรแกรมจะเคลียร์ Clipboard → ส่ง Ctrl+C → แปลงข้อความ → ส่ง Ctrl+V
ถ้าข้อความมีตัวอักษรไทยจะแปลงเป็นอังกฤษ ถ้าไม่มีจะแปลงเป็นไทย

## ข้อจำกัด

- ใช้ได้บน Windows เท่านั้น
- ขณะเปิดโปรแกรมอยู่ Ctrl+Q จะถูกโปรแกรมนี้ใช้ ปุ่มนี้ในแอปอื่นจะใช้ไม่ได้จนกว่าจะกดปิด
- แปลงตามผังแป้นเกษมณี ตัวเลขอังกฤษก็จะถูกแปลงเป็นอักขระไทยตามปุ่มด้วย (เช่น `1` → `ๅ`)
- ถ้าหน้าต่างที่ใช้งานอยู่ทำงานด้วยสิทธิ์ Administrator ต้องเปิดโปรแกรมนี้ด้วยสิทธิ์ Administrator เหมือนกัน
- เครื่องหมาย เช่น `.` `,` `(` `)` `?` เวลาแปลงจากไทยเป็นอังกฤษจะไม่ถูกแตะ เพราะบอกไม่ได้ว่ามาจากปุ่มไหน
